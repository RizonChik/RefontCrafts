# RefontCrafts — документация

**RefontCrafts** — GUI-плагин для кастомных крафтов в верстаке и наковальне на Minecraft-серверах.

Плагин подходит для survival, RPG, RP, economy и custom-серверов, где нужны собственные рецепты, права доступа и поддержка кастомных предметов.

## Возможности

- GUI-редактор рецептов верстака.
- GUI-редактор рецептов наковальни.
- Поддержка строгой выкладки 3x3 и бесформенных рецептов.
- Просмотр сохранённых рецептов игроками без OP.
- Поддержка кастомных предметов, зелий, CustomModelData, названий, лора, чар и PDC-данных.
- Мягкое сравнение предметов при `exact_meta_match: false`.
- Строгий порядок предметов в наковальне.
- Автообновление результата крафта при ЛКМ, ПКМ и drag-раскладке.
- Preview и выдача результата верстака стаками до `126`.
- SQLite по умолчанию, MySQL опционально.

## Установка

1. Скачай последнюю версию `.jar` из Releases или Modrinth.
2. Закинь файл в папку `plugins/`.
3. Перезапусти сервер.
4. Открой главное меню командой:

```text
/rcrafts
```

После первого запуска плагин создаст конфиг и базу данных.

## Важные настройки

```yaml
settings:
  exact_meta_match: false
  workbench_strict_shape: true
  workbench_preview_limit: 126

  anvil:
    strict_order: true
```

### `exact_meta_match`

- `true` — строгое сравнение предметов.
- `false` — сравнение по важным визуальным и логическим данным без уникальных служебных NBT.

Рекомендуется `false`, если сервер использует магазины, Brewery, ExecutableItems или другие плагины с кастомными предметами.

### `workbench_strict_shape`

Если включено, рецепт верстака сработает только при точной выкладке предметов по слотам 3x3.

### `workbench_preview_limit`

Лимит визуального количества результата в верстаке. Значение `126` используется как стабильный предел для отображения overstack-результата.

### `anvil.strict_order`

Если включено, левый и правый слоты наковальни считаются разными. Рецепт `A + B` не сработает как `B + A`.

## FAQ

### Почему результат показывает максимум 126?

Это практический предел стабильного клиентского отображения overstack-результата. При больших значениях слот результата может отображаться некорректно.

### Можно ли дать игрокам только просмотр рецептов?

Да. Достаточно прав:

```text
refontcrafts.use
refontcrafts.view
```
